# 第 0 阶段手动验收清单

## 启动

1. 使用 Unity `6000.3.19f1` 打开项目。
2. 打开 `Assets/Scenes/Stage0Prototype.unity`。
3. 进入 Play Mode。

场景启动时会自动创建 `16 × 10` 的水平 XZ 网格，以及一条完整的演示产线：

`采矿机 → 传送带 → 熔炉 → 传送带 → 存储箱`

## 核心闭环

1. 确认蓝灰色矿石从采矿机进入第一段传送带。
2. 确认矿石到达熔炉后消失，左上角状态显示熔炉开始加工。
3. 确认黄色铁锭从熔炉输出并继续沿传送带移动。
4. 确认铁锭进入存储箱，左上角 `Demo storage` 数量持续增加。
5. 删除演示线中的一段传送带，确认上游物品在末端阻塞且不会丢失。

## 建造交互

- `1`：选择传送带（占 `1 × 1` 格）。
- `2`：选择采矿机（占 `2 × 2` 格）。
- `3`：选择熔炉（占 `2 × 2` 格）。
- `4`：选择存储箱（占 `2 × 2` 格）。
- `R`：顺时针旋转当前待建建筑。
- `WASD`：控制上帝视角摄像机沿 XZ 网格平面移动。
- 按住鼠标右键并左右移动鼠标：摄像机仅绕世界 Y 轴旋转。
- 鼠标左键：在当前格建造，并在 Console 输出格子坐标。
- `F`：拆除鼠标当前指向格子上的建筑。

## 建造规则

- 建筑不能越过网格边界。
- 建筑不能与已有建筑重叠。
- 蓝色 `IN` 标记是输入端口，黄色 `OUT` 标记是输出端口。
- 传送带箭头必须指向下一段传送带或建筑本体。
- 机器端口外侧的相邻格用于放置传送带。
- 鼠标指向可建造的空格时，会显示半透明蓝色建筑预览。
- 每格传送带最多只能容纳一个物品；下游占用时，上游物品停在末端。
- 传送带运行时只保存一个 `currentItem` 引用，不再使用单元素 `List`。

完成以上检查后，请反馈第 0 阶段是否通过；在得到确认前不进入第 1 阶段。
