# 建筑占格与端口定义

建筑源数据为 `Assets/Data/FactoryTables/buildings/buildings.csv`。修改后使用
`Factory > Rebuild Static Database` 重新生成数据库，不要直接修改生成的 asset。

完整表结构见 [建筑数据表](Building-Data-Tables.md)。

## 占格字段

| 字段 | 含义 |
|---|---|
| `width` | 未旋转时局部 X 方向的包围矩形格数，正整数 |
| `length` | 未旋转时局部 Z 方向的包围矩形格数，正整数；不是物理高度 |
| `is_rectangle` | `true` 表示整个矩形占格；`false` 使用位图 |
| `bitmap` | 逐行的 0/1 字符串，用 `/` 分行；矩形时必须留空 |

例如，4×3 的异形占格配置为：

```text
width=4
length=3
is_rectangle=false
bitmap=1111/1111/1100
```

第一行对应局部 Z=0，第一列对应局部 X=0。`1` 占格，`0` 不占格。
行列数必须与尺寸一致，至少有一个 `1`。允许孔洞、不连通部分、空锚点和空白边界；
不会自动裁剪、重新居中或填洞。全 1 位图也有效。

锚点是旋转后包围矩形的最小 X/Z 格坐标，不要求该格被占用。
旋转沿用 QuarterTurns 的四向规则，模型以包围矩形中心对齐。
90°/270° 后包围矩形长宽交换，局部占格偏移、端口位置与方向同步旋转。

只有 `1` 需要可建造表面并参与占用冲突检查。空格不要求地基，可以放置其他建筑或
传送带。拆除只命中真实占格，点击包围矩形内部空格不会拆除这栋建筑。

本功能用于平面建筑占格，不定义物理碰撞，也不扩展斜坡、垂直运输等专用结构的建造规则。

## 端口坐标与方向

端口仍定义在 `building_ports.csv`：

- `cell_x/cell_z` 是未旋转时的局部连接格坐标，第二坐标对应世界 Z。
- 连接格位于建筑占格以外，可以在包围矩形外，也可以在内部的凹口或孔洞中。
- `direction_x/direction_z` 表示物品运动方向，只能是 `(1,0)、(-1,0)、(0,1)、(0,-1)`。
- 输入口的连接格加上方向，必须落在建筑占格上。
- 输出口的连接格减去方向，必须落在建筑占格上。
- `(type,index)` 必须唯一；相同类型、连接格、方向的重复端口也会被拒绝。
  同一个连接格可以用不同方向连接不同建筑边界。

上面例子的连接格 `(2,2)`，输入方向 `(0,-1)` 对应建筑格 `(2,1)`；
输入方向 `(-1,0)` 则对应建筑格 `(1,2)`。因此端口方向必须显式填写。

## 运行时数据

CSV 导入及 Blob 烘焙共用形状、端口校验。烘焙将矩形和位图统一展开成
`FactoryDatabaseBlob.BuildingOccupiedCells`，每种建筑通过
`OccupiedCellStart/OccupiedCellCount` 引用连续偏移列表。
放置候选、实体的 `OccupiedCellOffset` 和预览都读取该列表。
运行时不解析位图，也不需要按矩形/异形分支处理。

自动化回归见 `Assets/Tests/IrregularBuildingFootprintTests.cs`，覆盖四向放置、
预览、占用、拆除、空缺区域共存、稀疏表面、位图格式及凹边端口校验。
