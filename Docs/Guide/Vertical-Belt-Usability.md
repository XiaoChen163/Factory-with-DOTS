# 垂直传送带组合建造与图标配置

## 玩家操作

建造列表中只显示 `1级垂直传送带`～`4级垂直传送带` 四项，各自使用入口、中间段、出口叠放的组合图标。
三种节点及其稳定 ID、等级数据仍独立保留，目录分组不会更改既有建筑。

1. 选择等级，旋转入口的水平输入朝向，第一次单击实际放下入口。
2. 鼠标射线与经过入口中心、朝向当前视角的竖直平面相交。交点吸附到整数高度层，
   最终 X/Z 固定在入口所在柱内，选择上行／下行方向与长度。
   每帧按当前摄像机姿态重新求交，移动或旋转摄像机时，即使鼠标屏幕位置不变，出口也实时跟随。
   该虚拟平面不受中间地基或上层遮挡影响；高度限制在非负层及一次建造上限内。
   射线与平面平行、没有前向交点或视角完全垂直时隐藏预览并禁止确认。
3. 此时按 R 只旋转出口的水平输出朝向。预览显示细圆柱中间段、出口立方体与橙色输出箭头。
4. 第二次单击统一确认全部中间段和出口。途中存在占用冲突时不会放置半条新链路；已放下的入口保留。

每条链路至少包含一个中间段和一个出口，最多一次新增 256 个节点。按 Esc、切换建筑或退出建造模式时，
撤销尚未完成的本次建造，包括已经放下的入口；入口命令还未执行时立即取消也不会留下残留。
已成功完成的链路不会因为后续退出建造模式而被撤销。

从入口、中间段或出口任意节点执行拆除，会沿垂直连接一次移除整条链路，包含其所有表现、箭头与碰撞体。
不会跨过端点连接到相邻独立链路，也不会拆除相接的水平带或穿过的地基。
带内物品沿用普通传送带拆除时的物品回收处理。
第一下建造失败会退出本次手势；第二下提交失败则保留高度选择状态，允许调整后重试。

## 自定义图标

在 `Assets/Settings/FactoryIconBakeSettings.asset` 的 `overrides` 中添加对应建筑 prefab：

- `prefab`：需要配置图标的实际建筑 prefab。
- `customIcon`：可直接指定现有 Sprite，烘焙管线不会写入或覆盖该图片。
- `iconPrefab`：可指定专门用于图标的模型；仍自动渲染到原建筑对应的图标 PNG。
- 两者都不指定时继续自动渲染建筑自身模型；同时指定时优先使用 `customIcon`。
- 同一 override 的相机朝向、留白和中心偏移继续生效；自定义模型依赖变化也会参与增量烘焙失效。

建筑等级 CSV 的可选 `icon_key` 仍可直接引用其他图标，非空时优先于上述默认回退。空值与未配置一致。

四个等级的组合图标模型位于 `Assets/Prefabs/IconSources/VerticalBeltMk1.prefab`～`VerticalBeltMk4.prefab`，
由入口、中间段、出口的真实 prefab 组成，不会替换运行时建筑模型。
使用 `Factory/Assets/Rebuild Vertical Belt Catalog Icons` 可重建组合图标模型、图标和数据库，
`Factory/Icons/Bake Changed` 则只增量更新需要重新生成的图片。

## 实现与验证

组合放置通过现有玩家命令管线提交 `PlaceVerticalBeltPath`，先校验完整链路及其等级、方向、占用和 prefab，
全部成功后才创建实体。内部节点继续参与原有逐节点模拟与确定性显式运输拓扑。
竖直预览及点击确认在 LateUpdate 中读取相机本帧移动后的姿态，使用同一套实时射线求交规则。
取消命令通过玩家及原始建造请求 ID 匹配本次入口，避免快速取消或建造失败时误删其他建筑。
同批次刚创建就撤销的实体会在 ECB 引用解析完成后、运输更新前清理。
